# Personal Config

Personal configuration files and dotfile references.

## Structure

Add config files or subdirectories per tool. Example layout:

```
config/
  editor/         — editor settings (VS Code, Neovim, etc.)
  git/            — .gitconfig, commit templates, hooks
  shell/          — aliases, functions, env var templates
  ssh/            — SSH config templates (no private keys)
```
